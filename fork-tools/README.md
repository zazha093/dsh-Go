# Fork Tools

This directory contains fork-specific maintenance scripts for the dsh-Go Thai fork.

## Scripts

### `scan_th.py`
Thai localization scanner - scans ARB files for translation coverage and quality checks.

**Usage:**
```bash
python3 fork-tools/scan_th.py
```

### `scan_report.json`
Latest scan report output (generated by scan_th.py).

## Purpose

These tools help maintain the Thai fork by:
- Checking Thai translation completeness
- Verifying placeholder/ICU syntax consistency with English
- Identifying untranslated or problematic strings

## Maintenance

Run after updating Thai ARB files:
```bash
python3 fork-tools/scan_th.py
python3 app/tool/l10n_merge.py --locale th --check
```
